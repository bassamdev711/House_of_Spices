# طيف: فلسفة الضوء والعطر

[English Version / النسخة الإنجليزية](./README.md)

---


منصة "طيف" هي واجهة تجارة إلكترونية سينمائية متطورة، متخصصة في قطاع العطور الفاخرة. تجمع المنصة بين تقنيات العرض ثلاثي الأبعاد المتقدمة ومبادئ التصميم التقليلية (Minimalism) لخلق تجربة رقمية استثنائية.

## البنية التقنية للمشروع

### التقنيات الجوهرية
- **إطار العمل**: Next.js 16 (محسن باستخدام Turbopack)
- **لغة البرمجة**: TypeScript
- **محرك التنسيق**: Tailwind CSS v4
- **العرض ثلاثي الأبعاد**: Three.js & React Three Fiber
- **محرك الحركة**: Framer Motion
- **الأيقونات**: Lucide

### هيكلية الملفات
- `/app`: إدارة الصفحات والتوجيه المركزي.
- `/components`: المعمارية النمطية للواجهات (الواجهة الرئيسية، المنتجات، الإحصائيات).
- `/lib`: الأدوات الوظيفية ومنطق إدارة الطلبات المشفرة.
- `/public`: إدارة الأصول البصرية عالية الدقة.

## الخصائص الهندسية والجمالية

### 1. بوابة الدخول (Preloader)
تجربة دخول تقليلية تعتمد على خاتم كريستالي دوار وحركات تمدد دقيقة، تهدف إلى الحفاظ على هيبة العلامة التجارية أثناء تحميل الأصول التقنية.

### 2. التجسيد ثلاثي الأبعاد الواقعي
محاكاة لزجاجات العطر باستخدام بيئات إضاءة حقيقية، مما يمنح المستخدم شعوراً ملموساً بالفخامة داخل بيئة المتصفح.

### 3. التجاوب الحركي (Fluid Layout)
نظام تمرير أفقي مخصص للهواتف الذكية، مصمم لمحاكاة تصفح المجلات الفاخرة أو المحافظ الورقية الراقية.

### 4. الربط المباشر وإدارة الطلبات
أداة أمنة لبناء استفسارات المنتجات المنظمة، وتسهيل التواصل المباشر عبر بروتوكولات المراسلة العالمية.

## الدليل التقني للمساعد الذكي "كيرو" (Kiro AI Assistant)

تمت ترقية وتصميم المساعد الذكي **"كيرو"** ليكون مستشاراً تفاعلياً حياً فخماً لبراند "طيف"، ومحصناً ضد الضغط العالي ومحسناً للاستخدام المجاني غير المحدود.

### 1. المنطق التشغيلي والبنية (Architecture & Flow)
1. **واجهة الدردشة الكريستالية (`ChatWidget.tsx`)**:
   * واجهة زجاجية (Glassmorphic) راقية تدخل الموقع **بعد تأخير 3 ثوانٍ** بحركة دخول نابضة (Spring) لعدم تشتيت انتباه الزائر أثناء الـ Preloading الفاخر.
   * تحتوي على **أيقونة زجاجة عطر حية ومخصصة بالـ SVG** تبتسم ببرمجة تفاعلية وتغمز للعميل كل 4.5 ثانية، وعند تمرير الفأرة فوقها تتسع ابتسامتها ويرتفع غطاء الزجاجة قليلاً بحركات دقيقة تعطي شعوراً بالكفاءة والحيوية.
   * تعرض فقاعة ترحيب أنيقة ومؤقتة عند الظهور الأول ثم تختفي برقة بعد 5 ثوانٍ.
2. **ذاكرة المحادثة النشطة (Active Context Memory)**:
   * لحماية المساعد من نسيان السياق وتجنب تكرار عبارات الترحيب مع كل رسالة، تقوم الواجهة بقطع (Slice) لآخر 10 رسائل من سجل المحادثة وإرسالها في جسم الطلب (`history`) مع كل رسالة جديدة للعميل.
3. **خادم معالجة الطلبات (`app/api/chat-agent/route.ts`)**:
   * يستقبل الرسالة الجديدة وسجل المحادثة التاريخي.
   * يدمج التعليمات الحازمة والشعرية الفخمة المستقاة من دستور كيرو (`lib/agent-prompt.ts`) مع السجل التاريخي كحوار مرتب بين `العميل` و `كيرو` في Prompt متكامل يُمرر للذكاء الاصطناعي مع توجيه حازم بمنع تكرار الترحيب.

### 2. تدوير المفاتيح الذكي (API Key Rotation)
لمواجهة حدود الاستخدام الضيقة في الخطة المجانية، قمنا بابتكار آلية **تدوير المفاتيح العشوائي** في الخلفية:
* **آلية التدوير**: يتم جلب مفاتيح الـ API الثلاثة (`GEMINI_API_KEY_1`, `GEMINI_API_KEY_2`, `GEMINI_API_KEY_3`) وفلترتها تلقائياً لاستبعاد القيم الفارغة، ثم يتم اختيار مفتاح عشوائي عند كل طلب لتوزيع الضغط بالتساوي.
* **نظام التراجع الاحتياطي (Fallback)**: إذا لم يتم تحديد المفاتيح الجديدة بعد، يتراجع النظام تلقائياً وبأمان لاستخدام المفتاح الأساسي `GEMINI_API_KEY` دون أي تعطل للخدمة.
* **الجدول البياني للفائدة:**
  | اسم المفتاح | الطراز | الطلبات في الدقيقة (RPM) | الطلبات اليومية المتاحة (RPD) |
  | :--- | :--- | :--- | :--- |
  | مفتاح فردي واحد (سابقاً) | `gemini-2.5-flash` | 10 | 250 |
  | تدوير 3 مفاتيح مدمجة (حالياً) | `gemini-2.5-flash-lite` | **45** | **3,000** |

### 3. طراز الذكاء الاصطناعي الأفضل: `gemini-2.5-flash-lite` ⚡
* تم الانتقال رسمياً من `gemini-2.5-flash` إلى **`gemini-2.5-flash-lite`**.
* **السبب**: مصمم خصيصاً للمحادثات ذات الكثافة المرتفعة، ويمتلك سرعة استجابة استثنائية (Latency منخفض جداً)، وذاكرة سياقية ضخمة (مليون توكن)، وحدوداً مجانية أعلى بكثير وبلا أي تكاليف مادية.

### 4. التقنيات والمكتبات الجديدة المستعملة 🛠️
* **مكتبة الأيقونات `lucide-react`**: للتحكم برمز الإغلاق (`X`) والإرسال (`Send`) مع إزالة الرموز النجمية المشتتة.
* **التأثيرات الحركية الدقيقة (Micro-animations)**:
  * دمج أنماط حركية للواجهة العائمة (`float`) والتنفس التوهجي المضيء (`glowBreath`) وحركات الانزلاق (`slideIn`) والظهور المتدرج للنافذة (`fadeInScale`).
  * استخدام الـ **CSS Keyframes المدمجة** مع الـ **React States** للتحكم بملامح الأيقونة لتجنب أي مشاكل توافقية مع React 19 ولضمان أداء سلس بسرعة 60 إطاراً في الثانية.
